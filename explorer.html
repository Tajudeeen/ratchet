Requires a browser wallet holding the bound agent key. Sign EIP-712 typed data, then submit spend().

Boundaries: this is a testnet instrument. The owner key used in the public proof sequence is a development wallet; a fresh clone can deploy its own contract and reproduce every step. The off-chain verifier is a convenience caller — caps, expiry, revocation and idempotency are all enforced inside the contract.
