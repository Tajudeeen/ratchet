Reproduce a line

One command, from a fresh clone. It reads the transaction receipt, decodes the contract events, and prints the live remainingBudget() — no local deployment state, no trust in this site.

# local unit suite — 8 passing
npm install && npm run test

# re-read line 04 of the tape from Aevum chain state
npm run ratchet -- verify 0x51edfbf20500d8bef9307931e00b1e9b65364bfb83a3325197196eeada6e59ec

Output: chain id, receipt status, decoded PaymentSettled event, current budget, tUSD8 decimals and the explorer URL.

Why this shape

Problem sources are primary and dated: Circle, How AI Agents Hold and Spend Money (19 Nov 2026) — “A prompt that says ‘stay within budget’ expresses intent, but nothing enforces it”; EIP-3009 / ERC-7715 / x402 facilitator docs on signed authorizations and idempotency; the official Aevum challenge brief for the scoring weights and testnet parameters. Two competing invoice-escrow repos were checked before design, so the chosen shape — a capability lifecycle over one shared budget — is not a reskin.

Not claimed: no external audit, no mainnet deployment, no uptime guarantee, and no explorer source verification (Aevum's verifier is non-functional — repo + exact commit pin the source). The deployer wallet is a development wallet whose key was shared in a chat; rotate it before any real use.
